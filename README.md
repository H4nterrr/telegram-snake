# 🐍 Змейка — Telegram Mini App

Классическая «Змейка» для телефона и компьютера. Открывается внутри Telegram как Mini App и в обычном браузере. Сервер, база данных и регистрация не нужны: это статический сайт.

**Игра:** https://h4nterrr.github.io/telegram-snake/
**Текущая версия:** указана мелким текстом внизу стартового экрана (например, `v1.1.0`).

## Что умеет игра

- Классические правила: еда, рост, счёт, конец игры при столкновении со стеной или с собой. Если змейка заполнит всё поле 15×15, вы победили.
- Стартовый экран: рекорд, выбор из трёх скоростей, большая кнопка «Играть» и короткая подсказка.
- Три скорости: лёгкая, обычная и быстрая. Для каждой скорости свой рекорд, он хранится в `localStorage` на этом устройстве.
- Управление:
  - телефон: свайпы по игровой области (можно провести «уголком», чтобы повернуть два раза) или крупные кнопки‑стрелки под полем;
  - компьютер: стрелки или W A S D (работают и при русской раскладке); пауза — пробел, P или Esc; Enter — начать или сыграть ещё раз.
- Пауза и продолжение. Игра сама встаёт на паузу, если свернуть Telegram или переключить вкладку.
- Экран проигрыша появляется с небольшой задержкой и внизу, чтобы было видно, где змейка врезалась. Кнопка «Ещё раз» сразу начинает новую игру.
- Оформление «современная аркада»: тёмный фон, яркая змейка, коралловая еда, золотой рекорд. Шапка Telegram окрашивается в цвет игры.
- Учитываются вырезы экрана и панели Telegram. Во время игры ничего не прокручивается, свайп вниз не сворачивает Mini App.
- В Telegram: вибрация при еде, выборе скорости и в конце игры; системная кнопка «Назад» (в игре — пауза, на паузе — меню).

Технически: TypeScript + Vite + Canvas, без фреймворков. Аналитики, рекламы и внешних сервисов нет. Единственный внешний скрипт — официальный SDK Telegram `https://telegram.org/js/telegram-web-app.js`.

## Запуск на компьютере

Нужен Node.js 20.19 или новее. На этом Mac он уже установлен через Homebrew. На другом компьютере установите его командой `brew install node` (macOS) или скачайте с https://nodejs.org.

```bash
cd /Users/rudolfkehl/telegram-snake
npm install        # один раз: скачать зависимости
npm run dev        # запустить игру
```

Откройте в браузере адрес, который покажет команда (обычно http://localhost:5173/). Остановить сервер: `Ctrl + C`.

**Проверка на телефоне в той же Wi‑Fi сети:** `npm run dev` также выводит строку `Network: http://192.168.x.x:5173/`. Откройте этот адрес в браузере телефона. Внутри Telegram такой адрес не откроется: Telegram требует HTTPS.

## Проверки и сборка

```bash
npm run typecheck  # проверка типов TypeScript
npm test           # тесты игровой логики
npm run build      # проверка типов + сборка в dist/ + проверка путей в сборке
npm run preview    # посмотреть собранную версию: http://localhost:4173/
npx playwright install chromium   # один раз: браузер для проверки
npm run e2e        # проверка собранной игры в браузере (экран телефона)
npm run e2e -- https://h4nterrr.github.io/telegram-snake/   # то же для опубликованной игры
npm run check      # всё сразу: сборка, тесты, проверка в браузере
```

- **Тесты логики** проверяют движение, рост, счёт, столкновения со стенами и с собой, вход в клетку уходящего хвоста, запрет разворота на 180° (в том числе при быстрых нажатиях), появление еды только на свободных клетках, победу при заполнении поля и независимость скорости от частоты кадров.
- **Проверка сборки** (`scripts/check-dist.mjs`) убеждается, что все файлы, на которые ссылается `index.html`, лежат рядом с ним, пути относительные и номер версии подставлен. Именно из‑за отсутствующих файлов в версии 1.0.0 не работала кнопка «Играть».
- **Проверка в браузере** (`e2e/smoke.mjs`) нажимает «Играть» и проверяет, что змейка движется. Затем проверяет стрелки, свайп, запрет разворота, паузу без скачков, проигрыш и «Ещё раз», отсутствие лишних игровых циклов после перезапусков, скорости, рекорды и смену размера экрана.

## Публикация (GitHub Pages)

Игра опубликована на GitHub Pages из репозитория https://github.com/H4nterrr/telegram-snake. Это бесплатно, адрес HTTPS.

Публикация автоматическая: при каждом `git push` в ветку `main` GitHub Actions (файл `.github/workflows/deploy.yml`) по очереди:
1. собирает игру и проверяет типы, тесты и пути в сборке;
2. запускает проверку в браузере;
3. только если всё прошло, публикует новую версию;
4. ждёт, пока новая версия появится на публичном адресе, и повторяет проверку в браузере уже там.

Если какой‑то шаг не прошёл, на сайте остаётся предыдущая версия. Ход публикации виден на вкладке **Actions** репозитория.

**Как выпустить обновление:** измените номер версии в `package.json` (поле `version`), затем:

```bash
cd /Users/rudolfkehl/telegram-snake
npm run check
git add -A
git commit -m "Описание изменений"
git push
```

> Загружать файлы через сайт GitHub вручную больше не нужно и не стоит: исходники и сборка теперь хранятся раздельно, а собирает сайт GitHub Actions. Сборка всё равно сделана «плоской» (без подпапок), так что даже ручная загрузка содержимого `dist/` не сломает пути.

> Почему GitHub Pages, а не Cloudflare Pages: с июня 2025 года российские провайдеры замедляют сайты на Cloudflare, и у части друзей игра могла бы не загружаться.

## Подключение к Telegram

Порядок действий взят из официальной документации Telegram: https://core.telegram.org/bots/webapps и https://core.telegram.org/bots/features. Названия пунктов в @BotFather иногда меняются. Если какого‑то пункта нет, вместо него можно открыть мини‑приложение @BotFather (кнопка «Open») — там те же настройки в виде обычных экранов.

### 1. Создайте бота

1. Найдите в Telegram **@BotFather** (с синей галочкой) и нажмите «Запустить» / Start.
2. Отправьте команду `/newbot`.
3. Введите **имя** бота, которое будут видеть люди, например `Змейка`. Его можно поменять позже.
4. Введите **username** — латиница, цифры и `_`, от 5 до 32 символов, обязательно на `bot` в конце, например `my_snake_game_bot`. Поменять его потом нельзя.
5. BotFather пришлёт **токен** (длинная строка вида `123456:ABC...`). **Для этой игры токен не нужен.** Не вставляйте его в код, в репозиторий, в сайт и не отправляйте никому. Сохраните его в надёжном месте. Если токен утёк, его можно заменить командой `/token`.

### 2. Привяжите игру к кнопке меню бота

1. В @BotFather отправьте `/mybots` → выберите своего бота → **Bot Settings** → **Menu Button** → **Configure menu button**. Можно и короче: отправьте команду `/setmenubutton` и выберите бота.
2. Отправьте HTTPS‑адрес игры: `https://h4nterrr.github.io/telegram-snake/`.
3. Отправьте название кнопки, например `Играть`.

Теперь в чате с ботом слева от поля ввода появится кнопка «Играть». Она открывает игру.

### 3. (Необязательно) Главное мини‑приложение бота

Чтобы в профиле бота появилась крупная кнопка запуска, а игру можно было открыть прямой ссылкой `https://t.me/ИМЯ_БОТА?startapp`:
`/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → отправьте тот же HTTPS‑адрес.

### 4. (Необязательно) Описание бота

`/setdescription` → бот → текст, например: «Классическая змейка! Нажмите кнопку «Играть» внизу». Это описание люди видят до нажатия Start.

### 5. Играйте с друзьями

Отправьте друзьям ссылку `https://t.me/ИМЯ_БОТА`. Они нажимают Start, затем кнопку «Играть».

Важно знать:
- Боту не нужен свой сервер: кнопка меню открывает игру напрямую. Но на сообщения (например, на `/start`) бот отвечать не будет, потому что программы‑бота нет. Для этой игры она не нужна.
- Рекорды хранятся на каждом устройстве отдельно (в `localStorage`). Общего рейтинга между друзьями в этой версии нет.

## Как убедиться, что в Telegram открыта новая версия

Номер версии написан мелко внизу стартового экрана (например, `v1.1.0`). Если после обновления там всё ещё старый номер:
1. Полностью закройте Mini App (крестик или «Закрыть», а не просто свернуть) и откройте снова.
2. Подождите до 10 минут: GitHub Pages разрешает браузерам хранить копию страницы до 10 минут.
3. Если не помогло — в Telegram: Настройки → Данные и память → Использование памяти → **Очистить кэш**.

## Быстрая проверка на телефоне

1. Откройте бота и нажмите «Играть» в меню бота. Внизу стартового экрана должна быть нужная версия.
2. Нажмите большую кнопку **«Играть»**: змейка сразу поползёт вправо, внизу на пару секунд появится подсказка.
3. Поверните змейку свайпом по полю и стрелками под полем. Страница не должна прокручиваться, а Mini App — сворачиваться.
4. Быстро нажмите «вверх», затем «влево»: змейка повернёт дважды и не врежется сама в себя.
5. Нажмите паузу (кнопка справа вверху), затем «Продолжить»: змейка продолжит с того же места, без рывка.
6. Сверните Telegram и вернитесь: игра должна стоять на паузе.
7. Врежьтесь в стену: внизу появится «Игра окончена», «Ещё раз» сразу начинает новую игру.
8. Выйдите в меню, выберите другую скорость и сыграйте: рекорд у каждой скорости свой.

## Отладка внутри Telegram

По официальной документации:
- **Android:** включите отладку по USB, в Telegram откройте Настройки, дважды нажмите и удерживайте номер версии внизу → Debug Settings → **Enable WebView Debug**. Подключите телефон и откройте в Chrome на компьютере `chrome://inspect/#devices`.
- **iPhone:** в Telegram 10 раз нажмите на значок «Настройки» → **Allow Web View Inspection**. Подключите телефон к Mac и откройте Safari → меню Develop → ваше устройство.
- **Telegram для macOS (бета‑версия):** 5 раз нажмите на значок настроек → **Debug Mini Apps**. Затем правый клик в игре → Inspect Element.
